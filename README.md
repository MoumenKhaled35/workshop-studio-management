# 🎨 Creative Workshop & Studio Management System

A complete **Database Management System (DBMS)** project designed for managing a community arts center that offers creative studios, workshops, memberships, inventory tracking, and tool rental services.

The project was developed using **SQL Server**, **C# Windows Forms**, and **ADO.NET** to provide a fully connected desktop application with real database operations.

---

# 📌 Project Overview

The system helps creative centers efficiently manage:

* 🎨 Art Studios (Pottery, Painting, Digital Media, etc.)
* 🧑‍🎨 Resident Artists & Workshop Instructors
* 👥 Members & Subscriptions
* 📦 Raw Material Inventory
* 🛠️ Tool Rentals & Maintenance
* 📅 Workshop Scheduling & Registrations

---

# ⚙️ Features

## 🏢 Studio Management

* Manage creative studio spaces
* Store studio occupancy limits
* Track equipment available in each studio

## 🎨 Workshop Management

* Schedule workshops
* Assign resident artists as instructors
* Register members in workshops

## 👥 Membership System

* Manage member subscriptions
* Store member information and activity

## 📦 Inventory Tracking

* Track raw materials consumption
* Record materials allocated for each workshop

## 🛠️ Tool Rental System

* Rent high-end tools to members
* Track pick-up and return information
* Store return conditions for maintenance purposes

## 📊 Reporting & Queries

The system supports advanced SQL queries such as:

* Workshop with maximum participants
* Studios with no bookings
* Most active resident artist
* Inactive members
* Materials consumed per workshop
* Total rentals for each tool
